# Who uses Base Bash?

This page lists only permissioned, independently verifiable consumers. It is
intentionally empty until a downstream maintainer approves publication of a
name, deployment mode, supported v2 reference, and outcome. The project will
not invent users, infer production use from stars, or publish private details.
