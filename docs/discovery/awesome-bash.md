deliberately not a claim that the project has been accepted upstream.

## Submission gate

Submit only after the v2.0.0 release has a canonical immutable asset and the
following links are public and stable:

1. the five-minute adoption path in [`docs/v2/quickstart.md`](../v2/quickstart.md);
2. the support and security policies in [`docs/support-policy.md`](../support-policy.md);
3. the verified bundle/vendor workflow in [`docs/pinned-consumption.md`](../pinned-consumption.md);
4. the three reference applications and their benchmark methodology; and
5. the integration compatibility pins in
   [`integrations/compatibility.yaml`](../../integrations/compatibility.yaml).
