# Contributor Covenant Code of Conduct

We want base-bash-libs to be a safe, useful place to build reliable Bash
software. Contributors, maintainers, reviewers, and users are expected to
make participation harassment-free and to communicate with respect.

Unacceptable behavior includes harassment, discrimination, personal attacks,
deliberate disclosure of private information, threats, and unsafe conduct in
issue, review, chat, or release channels. Project disagreement is welcome when
it is specific, evidence-based, and directed at the work.

Report conduct concerns privately through the repository's GitHub security
contact or maintainer contact. Do not use a public issue for sensitive details.
The maintainers will acknowledge a report within 5 business days, protect the
reporter's privacy, investigate fairly, and communicate an outcome or status.
Actions may include a warning, mediation, moderation, or removal from project
spaces. Retaliation is not acceptable.

This code is adapted from the Contributor Covenant and is governed by the
project's support, security, and succession policies.
